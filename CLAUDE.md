# El Analista

Antes de tocar `src/el-analista.jsx`, lee
[INTEGRACION-SURECONOMICS.md](INTEGRACION-SURECONOMICS.md). El juego se publica
dentro de sureconomics.com copiando ese archivo de `main` tal cual, y ahí está
el contrato que no se puede romper: un solo import (`react`), los enganches del
ranking, las claves de `localStorage`, estilos bajo `.ea-root` y limpieza al
desmontar.

Las reglas de trabajo del equipo están en [CONTRIBUIR.md](CONTRIBUIR.md):
nunca directo a `main`, y `npm run sintaxis` y `npm run robustez` en verde antes
de proponer nada.
